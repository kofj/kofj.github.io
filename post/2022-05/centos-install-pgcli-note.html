Harbor 使用 PostgreSQL 数据库存储相关信息。我们的产品，同样使用 PostgreSQL，但是云上的 PG 管理界面，不能很方便的访问 PG。之前我使用 mycli，能够非常方便的访问 mysql。在网上搜索，找到了 PG 版本的对标工具，PGCLI。于是需要在服务器上安装 pgcli。本文记录在安装 pgcli 时遇到报错，进而处理失败的记录。
