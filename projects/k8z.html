A lightweight, modern mobile and desktop application for manage kubernetes. Easily for use fast, secure.

简介

k8z 是您口袋里的 Kubernetes 集群管理器。

它是一个用于管理 Kubernetes 集群的移动和桌面应用程序，提供集群的指标概述、Kubernetes 集群中所有资源的概述。 可以查看日志和事件或将 shell 放入容器中。
